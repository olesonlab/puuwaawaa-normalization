# Data

The case-study data (`pww_sdm_input_data.xlsx`) used for the tradeoff frontier
analysis are shared with the companion repository:

**[github.com/olesonlab/puuwaawaa-sdm](https://github.com/olesonlab/puuwaawaa-sdm)**

For the tradeoff frontier figure, clone both repositories side-by-side:

```bash
git clone https://github.com/olesonlab/puuwaawaa-normalization.git
git clone https://github.com/olesonlab/puuwaawaa-sdm.git
```

Then download `pww_sdm_input_data.xlsx` from the Zenodo archive and place it
in `puuwaawaa-sdm/data/` before running `tradeoff_frontier.py`.

Data archive: **https://doi.org/10.5281/zenodo.20369405**
